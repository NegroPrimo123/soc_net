# ⚡ CYBERPUNK GIFTS COLLECTION — Коллекция неоновых подарков

Коллекция из 5 высокотехнологичных подарков для социальных сетей (Telegram, ВКонтакте, Discord и др.), выполненных в бескомпромиссном стиле Киберпанк (темный карбон, неоновый блум Cyan & Magenta, плазменные ядра, HUD-элементы и цифровой глитч).

## 🎁 Список подарков:
1. **01_Кибер_Сердце** (.gif, .webp, .png)
   - Термоядерное механическое сердце из титана с пульсирующим плазменным ядром, искрами, контурами охлаждения и кардиограммой.
2. **02_Кибер_Череп** (.gif, .webp, .png)
   - Угловатый шлем-маска Кибер-Самурая / Они с лазерным визором, вращающимися голографическими прицельными кольцами и глитчем.
3. **03_Чип_Black_ICE** (.gif, .webp, .png)
   - Военный зашифрованный квантовый чип данных с бегущим лучом сканера, золотыми контактами и падающими потоками hex-кода матрицы.
4. **04_Кибер_Дрон** (.gif, .webp, .png)
   - Тактический стелс-дрон с реактивными плазменными двигателями, светящимся сенсором и круговым радарным сканером.
5. **05_Неоновый_Стимулятор** (.gif, .webp, .png)
   - Боевой нейро-инжектор с биолюминесцентной сывороткой, поднимающимися нанопузырьками, бегущим LED-индикатором и электрическими дугами.

## 📁 Форматы файлов:
- **.gif** — классический универсальный формат анимации для любых мессенджеров и соцсетей.
- **.webp** — лёгкий 24-битный формат со сверхчёткой неоновой подсветкой без ступенчатых градиентов.
- **.png** — статичный стикер в высоком разрешении.
- **index.html** — стильная интерактивная витрина в стиле киберпанк. Откройте двойным кликом в браузере.

Размер: 512 × 512 пикселей.
Частота: ~12.5 FPS (динамичный футуристичный темп).
