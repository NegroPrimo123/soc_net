# ПОЛНАЯ КОЛЛЕКЦИЯ КИБЕРПАНК-ПОДАРКОВ 

## Список подарков:
1. **01_Кибер_Катана** (.gif, .webp, .png) — Лазерный клинок с бегущим импульсом и кольцами энергии.
2. **02_Нейро_Визор** (.gif, .webp, .png) — Смарт-очки HUD дополненной реальности со сканирующим лучом.
3. **03_Квантовое_Сердце** (.gif, .webp, .png) — Плазменный термоядерный реактор с двойным пульсом.
4. **04_Шлем_Самурая** (.gif, .webp, .png) — Боевой шлем они с LED-визором и неоновыми рогами.
5. **05_Синтвейв_Кассета** (.gif, .webp, .png) — Неоновая кассета с вращающимися бобинами и эквалайзером.
6. **06_Клинок_Богомола** (.gif, .webp, .png) — Бионическая рука с раскалённым оранжевым термо-лезвием.
7. **07_Кибер_Дрон** (.gif, .webp, .png) — Стелс-дрон с плазменными двигателями и круговым радаром.
8. **08_ЭМИ_Граната** (.gif, .webp, .png) — Сферическая плазменная граната с электрическими дугами.
9. **09_Нейро_Инжектор** (.gif, .webp, .png) — Стимулятор MaxDoc со светящейся сывороткой и нанопузырьками.

## Форматы:
- **.webp** — ультра-чёткий 24-битный формат с плавным альфа-каналом.
- **.gif** — классический анимированный формат с прозрачным фоном.
- **.png** — статичный стикер в высоком разрешении.
- **index.html** — галерея-витрина для комфортного просмотра.

Разрешение: 512 × 512 пикселей.
